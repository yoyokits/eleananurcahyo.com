# eleananurcahyo.com

Website of Eleana Nurcahyo: a gallery of her paintings and handicrafts.

Static single-page site, published with GitHub Pages from the `/docs` folder on `main`.

## Adding artwork
1. Put the image in `docs/images/`.
2. Add an entry to the `works` list at the bottom of `docs/index.html`.

No photos of Eleana herself - artwork only.

## Hosting
- Pages: Settings > Pages > Deploy from branch > `main` / `/docs`
- Custom domain: eleananurcahyo.com (see docs/CNAME)
- DNS: apex A records 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153; www CNAME to yoyokits.github.io
